## Query structure

```saneql
data
  .filter(country = 'Switzerland')
  .group(by := {pangoLineage}, aggs := {count := count()})
```

Method syntax is equivalent to passing the value on the left as the first function argument. Named arguments use `:=`. After a named argument, all remaining arguments must also be named.

## Tables

The table holding the sequences and their metadata is named `data`. Further tables are queried like any other table:

- `reference_genomes` is a built-in table that every database contains. It holds the reference sequences, one row per sequence, with the string columns `name`, `type` (`nucleotide` or `amino_acid`) and `sequence`.
- A lineage column configured with `lineageIndexType: table` or `both` gets a lineage relation table named after the column. It holds one row per direct edge of the lineage tree, with the child in `lineage` and its direct parent in `parent` (null for roots), as well as `id`, `is_recombinant_edge` and `recombinant_clade_ancestor`.

[`tables()`](#tables-function) lists the tables of an instance.

## Operators

Boolean expressions use `&&` (and), `||` (or), and `!` (not). Parentheses control grouping.

A comparison takes a column identifier on one side and a literal on the other. The column may be on either side, so `age > 30` and `30 < age` are the same filter.

```saneql
country = 'Germany' && age >= 18
!(date < '2024-01-01'::date)
```

A boolean column can serve as a predicate on its own. `data.filter(isHuman)` means `isHuman = true`, and `data.filter(!isHuman)` is its complement. Only boolean columns may be written this way; a bare reference to a column of another type is rejected.

<Note title='Null values and comparisons'>
    A null cell never matches a comparison, `<>` included, so `country <> 'Germany'` leaves out the rows whose
    `country` is null. `!` is a set complement rather than SQL's `NOT`, so `!(country = 'Germany')` does return those
    rows. Comparing against the `null` literal is an error; use{' '}
    <a href={withBase('/docs/reference/functions#null')}>
        <code>isNull()</code> or <code>isNotNull()</code>
    </a>{' '}
    to test for missing values.
</Note>

## Pipeline operations

<ReferenceItem id='filter' name='filter(condition)'>
    <div slot='description'>
        <p>
            Keep the rows of the preceding result for which the condition is true. A filter can follow any operation,
            such as a <code>group</code>, a <code>map</code> that derives the filtered column, a <code>join</code>, or{' '}
            <code>schema()</code>.
        </p>
        <p className='mt-2'>
            A filter that applies to the rows of a table, directly or through <code>project</code>, a deterministic{' '}
            <code>order</code> or <code>unionall</code>, supports every predicate. On other results, a predicate can
            combine comparisons, boolean columns, and <code>isNull()</code> with <code>&amp;&amp;</code> and{' '}
            <code>||</code>.
        </p>
    </div>
    {`data.filter(country = 'USA' && age >= 18)
data.group(by := {country}, aggs := {count := count()}).filter(count > 1000)`}
</ReferenceItem>

<ReferenceItem id='group' name='group(by, aggs)'>
    <div slot='description'>
        <p>
            Aggregate rows. <code>by</code> is the set of grouping columns, and the empty set <code>&#123;&#125;</code>{' '}
            aggregates all rows into a single group. <code>aggs</code> is a record of named aggregates. The result has
            one row per group with the grouping columns and the aggregates. Rows with a null grouping value form their
            own group.
        </p>
        <div className='my-4 overflow-x-auto rounded-box border border-base-300'>
            <table className='table table-sm'>
                <thead>
                    <tr>
                        <th>Aggregate</th>
                        <th>Result</th>
                    </tr>
                </thead>
                <tbody>
                    <tr>
                        <td>
                            <code>count()</code>
                        </td>
                        <td>The number of rows in the group, as an int64.</td>
                    </tr>
                    <tr>
                        <td>
                            <code>sum(column)</code>
                        </td>
                        <td>
                            The sum of a numeric column. Integer columns sum to an int64 and float columns to a float.
                            Null values are skipped; a group without any non-null value sums to null.
                        </td>
                    </tr>
                </tbody>
            </table>
        </div>
    </div>
    {`data.group(by := {}, aggs := {count := count()})
data.group(by := {country, pangoLineage}, aggs := {count := count()})
data.group(by := {country}, aggs := {count := count(), totalAge := sum(age)})`}
</ReferenceItem>

<ReferenceItem id='project' name='project(expressions)'>
    <span slot='description'>Return only the columns in the given set. At least one column must be kept.</span>
    {`data.project({primaryKey, country, date})`}
</ReferenceItem>

<ReferenceItem id='projectout' name='projectout(remove)'>
    <span slot='description'>
        Return all columns except the ones in the given set, in their original order. Every named column must exist, and
        at least one column must remain.
    </span>
    {`data.projectout({main, unaligned_main})`}
</ReferenceItem>

<ReferenceItem id='map' name='map(expressions)'>
    <span slot='description'>
        Add or replace columns using name-and-value assignments. Values may be literals, columns, or non-boolean scalar
        functions.
    </span>
    {`data.map({cohort := 'A', copiedCountry := country, week := date.isoWeek()})`}
</ReferenceItem>

<ReferenceItem id='order' name='order(by)'>
    <span slot='description'>
        Sort by a set of keys, each a bare column name (ascending) or an asc/desc expression.
    </span>
    {`data.order(by := {date.desc(), primaryKey})`}
</ReferenceItem>

<ReferenceItem id='limit' name='limit(count)'>
    <span slot='description'>Return at most count rows.</span>
    {`data.limit(100)`}
</ReferenceItem>

<ReferenceItem id='offset' name='offset(count)'>
    <span slot='description'>Skip count rows. Use a deterministic order when paginating.</span>
    {`data.order(by := {primaryKey}).offset(100).limit(100)`}
</ReferenceItem>

<ReferenceItem id='randomize' name='randomize([seed := n])'>
    <span slot='description'>Return rows in random order. A seed makes the order reproducible.</span>
    {`data.randomize(seed := 42).limit(10)`}
</ReferenceItem>

<ReferenceItem id='join' name='join(left, right, on [, type := kind])'>
    <div slot='description'>
        <p>
            Combine two pipelines by equality between columns. Multiple equalities may be joined with{' '}
            <code>&amp;&amp;</code>. The default type is <code>inner</code>. The two inputs must use disjoint column
            names. A filter after a <code>join</code> applies to the joined rows; apply sequence predicates such as{' '}
            <code>hasMutation()</code> to an input pipeline instead.
        </p>
        <div className='my-4 overflow-x-auto rounded-box border border-base-300'>
            <table className='table table-sm'>
                <thead>
                    <tr>
                        <th>Type</th>
                        <th>Kept rows</th>
                        <th>Output columns</th>
                    </tr>
                </thead>
                <tbody>
                    <tr>
                        <td>
                            <code>inner</code>
                        </td>
                        <td>Matching pairs only (default)</td>
                        <td>Left and right</td>
                    </tr>
                    <tr>
                        <td>
                            <code>left</code>
                        </td>
                        <td>All left rows; right columns are null-filled when unmatched</td>
                        <td>Left and right</td>
                    </tr>
                    <tr>
                        <td>
                            <code>right</code>
                        </td>
                        <td>All right rows; left columns are null-filled when unmatched</td>
                        <td>Left and right</td>
                    </tr>
                    <tr>
                        <td>
                            <code>full</code>
                        </td>
                        <td>All rows from both sides; the unmatched side is null-filled</td>
                        <td>Left and right</td>
                    </tr>
                    <tr>
                        <td>
                            <code>leftSemi</code>
                        </td>
                        <td>Left rows with a match</td>
                        <td>Left only</td>
                    </tr>
                    <tr>
                        <td>
                            <code>rightSemi</code>
                        </td>
                        <td>Right rows with a match</td>
                        <td>Right only</td>
                    </tr>
                    <tr>
                        <td>
                            <code>leftAnti</code>
                        </td>
                        <td>Left rows without a match</td>
                        <td>Left only</td>
                    </tr>
                    <tr>
                        <td>
                            <code>rightAnti</code>
                        </td>
                        <td>Right rows without a match</td>
                        <td>Right only</td>
                    </tr>
                </tbody>
            </table>
        </div>
    </div>
    {`data.group(by := {pangoLineage}, aggs := {countWorld := count()})
  .join(
    data
      .filter(country = 'Spain')
      .group(by := {pangoLineage}, aggs := {countSpain := count()})
      .map({pangoLineage2 := pangoLineage})
      .project({pangoLineage2, countSpain}),
    pangoLineage = pangoLineage2,
    type := left
  )`}
</ReferenceItem>

<ReferenceItem id='unionall' name='unionall(left, right)'>
    <span slot='description'>
        Concatenate two results with identical column names, types, and order. Duplicate rows are retained.
    </span>
    {`data.filter(country = 'Germany').project({country})
  .unionall(data.filter(country = 'France').project({country}))`}
</ReferenceItem>

<ReferenceItem id='schema' name='schema()'>
    <span slot='description'>
        Describe the schema of a table or of any pipeline result without reading its rows. Returns{' '}
        <code>fieldName</code> and <code>type</code>.
    </span>
    {`data.schema()
data.group(by := {country}, aggs := {count := count()}).schema()`}
</ReferenceItem>

<ReferenceItem id='tables-function' name='tables()'>
    <span slot='description'>
        List the tables of the instance as rows with a single <code>tableName</code> column. It takes no arguments and
        starts a pipeline instead of following a table.
    </span>
    {`tables()`}

## Sequence aggregations

<Note>
    These operations aggregate changes across the input rows. A preceding `filter` chooses the records to analyze; it
    does not restrict which changes the aggregation returns.
</Note>

<ReferenceItem id='mutations' name='mutations(minProportion := p [, sequenceNames := {...}] [, fields := {...}])'>
    <span slot='description'>
        Aggregate nucleotide substitutions and deletions above a frequency threshold. Returns source and observed
        symbols, position, sequence name, proportion, coverage, and count.
    </span>
    {`data.filter(country = 'Switzerland')
  .mutations(minProportion := 0.05, sequenceNames := {main})`}
</ReferenceItem>

<ReferenceItem id='amino-acid-mutations' name='aminoAcidMutations(minProportion := p [, ...])'>
    <span slot='description'>Aggregate amino-acid substitutions and deletions above a frequency threshold.</span>
    {`data.aminoAcidMutations(minProportion := 0.1, sequenceNames := {S})`}
</ReferenceItem>

<ReferenceItem id='insertions' name='insertions([sequenceNames := {...}])'>
    <span slot='description'>
        Aggregate every nucleotide insertion in the input rows by sequence, position, and inserted symbols.
    </span>
    {`data.insertions(sequenceNames := {main})`}
</ReferenceItem>

<ReferenceItem id='amino-acid-insertions' name='aminoAcidInsertions([sequenceNames := {...}])'>
    <span slot='description'>
        Aggregate every amino-acid insertion in the input rows by sequence, position, and inserted symbols.
    </span>
    {`data.aminoAcidInsertions(sequenceNames := {S})`}
</ReferenceItem>

## Graph operations

<ReferenceItem
    id='transitive-closure'
    name='transitiveClosure(input, from, to [, includeVertices := bool] [, startingFrom := {...}])'
>
    <div slot='description'>
        <p>
            Treat each input row as an edge from its <code>from</code> column to its <code>to</code> column, both of
            type string and written as column names, and return a <code>from</code> and <code>to</code> row for every
            pair connected by one or more edges. Rows with a null vertex are ignored.{' '}
            <code>includeVertices := true</code> adds the pair <code>(v, v)</code> for every vertex.{' '}
            <code>startingFrom</code>, a set of string literals, restricts the result to paths that start at the given
            vertices. The row order is unspecified.
        </p>
        <p className='mt-2'>
            On a lineage relation table, which lists each lineage with its parent, the closure from <code>parent</code>{' '}
            to <code>lineage</code> pairs every lineage with each of its descendants. The example counts the sequences
            of a lineage and all its sublineages.
        </p>
    </div>
    {`pangoLineage
  .transitiveClosure(parent, lineage, includeVertices := true, startingFrom := {'B.1.1.7'})
  .join(data.map({lineageName := pangoLineage}).project({lineageName}), to = lineageName)
  .group(by := {from}, aggs := {count := count()})`}
</ReferenceItem>

## Write statements

<ReferenceItem id='insert-into' name='insertInto(query, table)'>
    <div slot='description'>
        <p>
            Run a query and insert its rows into an existing table, given by its name. Output columns are matched to the
            target columns by name: every target column must be produced with a matching type, and additional columns
            are ignored. Sequence columns cannot be inserted.
        </p>
        <p className='mt-2'>
            <code>insertInto</code> must be the outermost operation of a query. It is sent to the{' '}
            <a href={withBase('/docs/reference/http-api#post-adminquery')}>
                <code>POST /admin/query</code>
            </a>{' '}
            endpoint, which saves the result as a new data version.
        </p>
    </div>
    {`source.filter(country = 'Switzerland').project({primaryKey, country}).insertInto(archive)`}
</ReferenceItem>
